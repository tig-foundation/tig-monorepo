## Additional Details

sigma_freud_v11 is a completely overhauled hypergraph solver, taking inspiration from exact_round_engine and improving runtimes by up to 25% over exact_round_engine, including a 400% runtime reduction for 10k hyperedges with 0 quality loss. Higher qualities on all tracks (even though track 1 on exact_round_engine appears to create invalid solutions)

Default effort is 5 on every track.

Recommended fuel setting is 5T, however when testing with test_algorithm the default 100B produced all valid solutions
