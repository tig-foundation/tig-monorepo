## Additional Details

This is an improved version of hgs_epure, achieving higher qualities across all tracks withint the same sort of runtime.
Tested on live network instances and bundle sizes.

It used the new Talos system from TIG with ideas in the `--description` flag, aimed at increasing quality while 
maintaining runtime as close as possible. The LLM used was GPT 6 Sol on `medium` thinking.

No hyperparameters are needed, as the defaults are set to the best performing sets.
